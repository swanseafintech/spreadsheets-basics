# Unicode Cheat Sheet (v0.0.1)

## Introduction

This is the first draft of a simple Unicode cheat sheet.
Originally, the purpose of this document is to aid in typing up raw notes in lecture notes.
I could have more headings for my tables but this is a first draft.
For the purpose of simplicity I have refrained from entering U+ for every hex-code entry
It is worth mentioning that the way in which you enter Unicode varies,
For example in vim it is ctrl + shift + U followed by the 4 digits of hexadecimal code.
